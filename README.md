# CNN Image Classification Task

This project implements a Convolutional Neural Network (CNN) for image classification using the CIFAR-10 dataset.

## Features
- CIFAR-10 dataset download
- Normalization and data augmentation
- Alternating convolution and max-pooling layers
- Batch Normalization and Dropout
- Adam optimizer
- Training/validation loss and accuracy curves
- Confusion matrix and classification report
- Saved PyTorch model weights

## Run
```bash
pip install -r requirements.txt
python src/cnn_model.py
```
